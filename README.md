## 🎯 Overview

See how 9 ink colours perform across all 6 Fitzpatrick skin types. Visibility scores, fade rates, and artist notes for any client's skin tone.

**Category:** Tattoo Engineering

This is a free, open-source widget from the [Poli International Widget Suite](https://poliinternational.com/tools/) - a collection of practical tools for tattoo and piercing studios, artists, and clients. It runs entirely in the browser; no data is sent to a server.

---

## ✨ Features

- ✅ **Tattoo Ink Skin Tone**
- ✅ **Fitzpatrick Skin Type Tattoo**
- ✅ **Pigment Visibility Dark Skin**
- ✅ **White Ink Dark Skin**
- ✅ **Tattoo Colour Guide**
- ✅ **Ink Fade Rate**
- ✅ **Responsive Design** - works on desktop, tablet, and mobile.
- ✅ **Free & Open Source** - MIT licensed.

## 🚀 Installation

### Option 1: Use Online (Recommended)

No installation needed! Just visit:
**[https://poliinternational.com/tools/skin-tone-pigment-matcher/](https://poliinternational.com/tools/skin-tone-pigment-matcher/)**

### Option 2: Run Locally

This tool is pure HTML/CSS/JS - no build step. Clone the repo and open `index.html`:

```bash
git clone https://github.com/Poli-International/skin-tone-pigment-matcher.git
cd skin-tone-pigment-matcher
# open index.html in your browser
```
